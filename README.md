## Overview

## Demo

**The camera driving the avatar**

The phone camera as the input, producing the same output as the headband. Face, head, hands and fingers move the same MetaHuman over the same Live Link stream, through the same mixer. Only the sensor has changed.

[![The camera driving the avatar](https://automatrixlab.com/platform-demos/posters/brain-desk-camera-avatar.jpg)](https://automatrixlab.com/adnan/devices#devices-camera-vision)

**Watch the demo:** https://automatrixlab.com/platform-demos/brain-desk-camera-avatar.mp4

**The phone camera as the eyes**

The live phone camera pointed at products on the desk, answering typed and spoken questions from what it can see at that moment.

[![The phone camera as the eyes](https://automatrixlab.com/platform-demos/posters/brain-desk-vision.jpg)](https://automatrixlab.com/adnan/devices#devices-camera-vision)
